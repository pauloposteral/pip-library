# Provenance

All PIP prose, templates, tests and utilities were authored for this distribution from the owner's approved public-library mission. No private application file or history was exported. Provider configuration examples were written against official documentation rather than copied from a private application.

The complete inventory is [export-policy.json](../export-policy.json); [MANIFEST.sha256](../MANIFEST.sha256) records hashes for every allowlisted file except itself. Git records the manifest's own bytes. Each entry has an origin, license status and sensitivity classification.

Third-party material is link-only except the standard MIT license text. Installed npm dependencies and GitHub Actions execute under their upstream licenses and are not vendored. See [NOTICE](../NOTICE.md) and [dependency inventory](dependencies.md).

Approval of a hash means a review covered those bytes, not that a later changed file is automatically approved. The independent review receipt records the reviewed tree; the maintainer must reconcile any later diff.
