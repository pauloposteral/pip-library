# Frequently asked questions

## Does PIP execute my private project?

No. The public library provides guidance and local validation. Its public MCP provides three information tools only.

## Is a generated report verified evidence?

Only when it links to actual execution receipts for the stated commit and scope. A valid format cannot establish that a command ran.

## Must I connect a paid AI service?

No. Start with a Markdown template. Optional client conversations may have their own plans; the library does not supply or resell inference.

## Is this Superpowers under another name?

No. Superpowers is Jesse Vincent's independent methodology. PIP provides original artifact and evidence guidance, with attribution and no copied upstream skills.

## Are Assurance and Cloud available?

They are future concepts. No price, subscription, SLA or production Engine is offered by this release.
