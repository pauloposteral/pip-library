# Vision and roadmap

| Product | Intended scope | Current release boundary |
| --- | --- | --- |
| PIP Public Library | Free knowledge, original skills, templates and integration examples | Private v0.1.0 candidate, publication gated |
| PIP Assurance | Authenticated, commit-linked QA evidence and cross-agent development history | Future concept; no hosted customer evidence service claimed |
| PIP Cloud | Private projects, team permissions, persistent workspaces and controlled automation | Future concept; no live commercial subscription |
| PIP Build Engine | Isolated execution, verified images, previews, testing, recovery and rollback | Future security-gated service; no public execution endpoint |

Next milestones are evidence-led: publish the safe library; observe real onboarding; validate an independently reproduced release report; test demand for hosted evidence; separately verify runtime and financial controls. No dates are promises. Pull requests and prototypes do not establish production readiness.

See the [90-day program](growth/30-60-90-days.md) and [commercial gates](governance-and-monetization.md).
