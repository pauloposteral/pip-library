# Contribute a reproducible example

Choose a small problem other users can reproduce without private data. State prerequisites, instructions, expected outcome and the actual status. Include author and license. Run the library checks, update the reviewed manifest and submit a focused PR. The reviewer should be able to distinguish a useful synthetic fixture from a test that really ran.

[Open the worked resource](../../CONTRIBUTING.md).

This tutorial is prepared for the candidate; publication and user completion have not been measured.
