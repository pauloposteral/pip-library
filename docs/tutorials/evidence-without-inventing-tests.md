# Write evidence without inventing tests

Record the exact commit before running a check. Capture its actual command, environment, UTC time, output and exit code. Hash the output. If the check was blocked, record the reason and leave the exit code null. If only a sample exists, call it synthetic. A report with no supporting execution remains UNVERIFIED. Ask someone else to reproduce one important claim.
