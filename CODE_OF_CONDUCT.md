# Community code of conduct

Treat participants with respect. Discuss ideas and evidence without harassment, discrimination, threats, doxxing or personal attacks. Keep feedback specific and constructive. Credit other people's work and respect consent, confidentiality and accessibility needs.

Posteral maintains this community and may hide abusive content, close disruptive threads or restrict repeat offenders. Apply moderation consistently and explain non-sensitive decisions. Anyone involved in a complaint should not be its sole reviewer.

Use the repository's private reporting option when available for confidential concerns. If it is unavailable, open a content-free request for a private contact channel; do not post personal allegations or identifying details. No private channel or response SLA is claimed before it is configured. This is original PIP policy, not a copied external code of conduct.
